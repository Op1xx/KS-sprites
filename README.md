# Katawa Shoujo Assets

This repository contains extracted in-game assets from the visual novel **Katawa Shoujo**, including character sprites, backgrounds, music, and sound effects. 

Everything is fully unpacked and ready to use.

## 🤗 Hugging Face Mirror
This project is also available as a dataset on Hugging Face! You can find it here:
👉 **[Hugging Face Dataset Mirror](https://huggingface.co/datasets/MaximSkuf/KS-sprites/tree/main)**

## 🛠️ Extraction Method
All assets in this repository were extracted directly from the original game files using the [unrpa](https://github.com/lattyware/unrpa) tool.

## 📂 Repository Structure
* `sprites/` – Character sprites, poses, and expressions.
* `backgrounds/` – In-game background illustrations.
* `music/` – Original soundtrack (BGM) in audio formats.
* `sfx/` – Ambient sounds and sound effects.
